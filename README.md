# 送貨路線小幫手

目前做到第 02 張任務：主畫面透過中繼伺服器查地址位置。中繼伺服器的程式在 relay 資料夾，設定步驟在 docs/cloudflare-setup.md。

## 怎麼打開

平常從網址打開：https://anacy888.github.io/route-helper/

直接用檔案打開 `index.html` 時清單可以用，但地圖和地址查詢不會動。

## 怎麼跑檢查

需要先裝好 Node.js 和 Playwright，然後在這個資料夾執行：

```
npm test
```

## 注意

這個資料夾之後會放上公開的 GitHub。真實的收件地址和截圖不要放進來。

## 地址查詢的使用規定

地址找位置用的是 Google 地址查詢，經過我們自己的中繼伺服器（Cloudflare），金鑰只放在 Cloudflare 的祕密設定裡，不放在這個資料夾。

重點：
1. 中繼伺服器每天（臺灣時間）最多查 300 次，主畫面清單上方會顯示今天用了幾次。
2. 查到的位置在這台裝置最多留 30 天，超過就重新查（Google 的規定）。
3. 查到的位置只能顯示在 Google 地圖上。
4. 地圖用的金鑰寫在 js/config.js，本來就是公開的，靠「只允許這個網址使用」保護。
